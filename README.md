# Diabetes Risk Predictor

A machine learning-based web application that predicts diabetes risk from user-provided health information.

The project combines a Python-based prediction model with a simple web interface, allowing users to enter health-related details and receive a diabetes risk prediction.

## Features

* User-friendly web interface for entering health information
* Diabetes risk prediction using a machine learning model
* Data processing and prediction using Python
* Displays the prediction result through the web application
* Flask-based backend for connecting the model with the interface

## Technologies Used

* Python
* Flask
* HTML
* CSS
* Pandas
* NumPy
* Scikit-learn

## How It Works

1. The user enters the required health information through the web interface.
2. The application processes the input data.
3. The trained machine learning model uses the processed information to generate a prediction.
4. The prediction result is displayed on the web page.
